# [归档] ADXL345 时域积分振动测量（第一版）

> 这是本项目的**早期版本**，已停止维护，仅作为开发历程保留。
> 当前版本（STM32F411 + ICM-42670-P，FFT 频域积分）请见 [main 分支](https://github.com/Asuka0001/stm32-vibration-monitor)。

## 方案概述

| 项目 | 说明 |
|---|---|
| MCU | STM32F103ZET6（72 MHz） |
| 传感器 | ADI ADXL345 三轴加速度计（SPI，Mode 3，2.25 MHz） |
| 采样方式 | TIM2 产生 1 kHz 定时中断，主循环中轮询读取 |
| 调试输出 | USART1 115200，双缓冲 DMA 发送 |

接线：CS = PA4，SCK / MISO / MOSI = PA5 / PA6 / PA7，UART TX / RX = PA9 / PA10。

### 处理流程

```
ADXL345 ──SPI──▶ 加速度 (g)
                   │
                   ├─▶ 一阶低通估计重力 → 相减得到线加速度
                   │        │
                   │        ▼
                   │   ZUPT 静止检测（60 ms 窗口方差）
                   │        │ 静止：速度清零 + 学习加速度偏置
                   │        ▼ 运动：梯形积分 → 速度 × 阻尼系数
                   │   速度 (mm/s)
                   │
                   └─▶ 合加速度幅值 → 1 s 窗口 RMS / 峰值
                                     → 过阈值计数估计振动频率
```

主要代码：

- [`MDK-ARM/ADXL345_SPI/adxl345.c`](MDK-ARM/ADXL345_SPI/adxl345.c)：驱动、重力分离、ZUPT、速度积分
- [`MDK-ARM/vibration_monitor.c`](MDK-ARM/vibration_monitor.c)：振动 RMS、峰值、频率估计

## 遇到的问题

### 1. 时域积分：漂移与迟钝无法兼顾

速度由加速度直接积分得到：

```c
v += (a_prev + a) * 0.5f * dt * g;   // 梯形积分
v *= ADXL_VELOCITY_DAMPING;          // 0.9992，每个采样周期衰减
```

- 加速度中任何微小的偏置或低频噪声，积分后都会线性累积，**速度持续漂移**。
- 为抑制漂移加入了阻尼（泄漏积分），本质上相当于对速度做一阶高通。阻尼弱则漂移依旧，阻尼强则真实的速度变化也被快速衰减，**输出变得迟钝、读数偏小**。
- 叠加 ZUPT 清零与偏置在线学习后，参数之间相互耦合，很难在各种工况下同时调好。

### 2. 重力分离会吃掉低频振动

重力通过一阶低通（α = 0.8 ~ 0.9，1 kHz 采样）估计，其截止频率在十几到几十赫兹量级，因此**低于该频率的真实振动会被当作"重力"减掉**。

### 3. 振动指标不够严谨

- RMS 基于包含重力的合加速度幅值计算，静止时也约为 1 g，无法直接反映振动强度。
- 频率通过信号过阈值的时间间隔估计，且限定在约 1.5 ~ 6 Hz 范围内，只能识别单一低频主频。

## 后续改进（见 main 分支）

上述问题促使第二版改为 **频域方案**：

| | 第一版（本分支） | 第二版（main） |
|---|---|---|
| 平台 | STM32F103 + ADXL345 | STM32F411 + ICM-42670-P |
| 采样 | 定时器轮询，1 kHz | 数据就绪中断 + SPI DMA，1.6 kHz |
| 去重力 / 低频 | 一阶低通估计重力 | 4 阶 Butterworth 高通 |
| 速度计算 | 时域积分 + 阻尼 | FFT 后逐频点除以 2πf（频域积分） |
| 频率识别 | 过阈值计时，单一频率 | 1024 点 FFT，前 3 个峰值 + 插值 |
| 振动指标 | 合加速度 RMS（含重力） | 频段内速度 RMS（ISO 10816 指标） |

频域积分不存在积分累积问题，也不需要阻尼，从原理上避开了第一版的漂移与迟钝之间的矛盾。
