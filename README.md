# STM32F411 三轴振动监测系统（ICM-42670-P）

基于 STM32F411CEU6 与 TDK ICM-42670-P 六轴 IMU 的嵌入式振动监测方案。系统以 1.6 kHz 对三轴加速度进行采样，在 MCU 端完成数字滤波、FFT 频谱分析与频域积分，实时输出各轴主振动频率及 **振动速度有效值（Velocity RMS, mm/s）**——即 ISO 10816 / ISO 20816 系列标准中评价机械振动烈度所用的指标。

## 功能特性

- **低 CPU 开销的数据采集**：传感器数据就绪中断（INT1）触发 EXTI，由 SPI + DMA 一次性读取 6 轴 14 字节数据，双缓冲交替接收
- **采集链路自恢复**：周期性检查 DMA 完成计数，连续停滞时自动复位 SPI/DMA 并重新初始化传感器
- **数字滤波**：基于 CMSIS-DSP 的 4 阶 Butterworth 高通（1 Hz）+ 4 阶低通（600 Hz），级联 Biquad（DF2T）实现
- **频谱分析**：去直流 → Hann 窗 → 1024 点实数 FFT，频率分辨率 1.5625 Hz，支持多帧频谱平均
- **峰值识别**：每轴输出前 3 个谱峰，抛物线插值获得亚频点精度的峰值频率
- **振动烈度**：频域积分（加速度谱 ÷ 2πf）计算三轴及合成速度 RMS
- **姿态与时域速度**：四元数互补滤波估计姿态、去除重力得到线加速度，时域积分得到速度 RMS，用于与频域结果交叉对照
- **非阻塞调试输出**：环形缓冲区 + UART DMA 发送，不阻塞主循环

```
ICM-42670-P ──INT1──▶ EXTI0 ──▶ SPI1 DMA 读取（双缓冲）
                                     │
                                     ▼  主循环
                           原始数据 → 物理量（g / dps）
                    ┌────────────────┴─────────────────┐
                    ▼                                  ▼
          带通滤波 1–600 Hz                     姿态估计（400 Hz）
          (4阶 Butterworth ×2)              四元数互补滤波 + 重力去除
                    │                                  │
                    ▼                                  ▼
       1024 点缓冲（每轴双缓冲）                 时域积分 + 高通
                    │                                  │

                    │
          ┌─────────┴──────────┐
          ▼                    ▼

          │                    │
          └──────────┬─────────┘
                     ▼
            UART DMA 输出（每秒 1 次）
```

## 算法说明

### 1. 预处理

两个 2 阶 Biquad 节级联构成 4 阶 Butterworth（Q = 0.5412、1.3066），系数在初始化时按 RBJ 公式计算。高通去除重力分量与零漂，低通抑制接近奈奎斯特频率的混叠成分。

### 2. 频谱计算

每轴累积 1024 个滤波后样本，减去均值后乘以 Hann 窗，用 `arm_rfft_fast_f32` 计算实数 FFT。幅值按 `2√2 / N` 缩放：其中 `2/N` 为单边谱幅值归一化，`×2` 补偿 Hann 窗相干增益（0.5），`÷√2` 将峰值转换为有效值。因此频谱每个频点的单位为 **g (RMS)**。

### 3. 峰值频率插值

在局部极大值处取相邻三点 `y0, y1, y2`，按抛物线拟合求偏移量：

```
δ = 0.5 · (y0 − y2) / (y0 − 2·y1 + y2),   f_peak = (k + δ) · fs / N
```

使频率估计精度优于 1.5625 Hz 的频点间隔。

### 4. 频域积分求速度 RMS

正弦振动中速度幅值 = 加速度幅值 / (2πf)。对积分频段内每个频点：

```
v_k = a_k · g · 1000 / (2π f_k)          [mm/s]
v_rms = sqrt( Σ v_k² )
```

三轴合成值为 `sqrt(vx² + vy² + vz²)`。相比时域直接积分，频域积分可以避免积分漂移，且容易限定频段。

### 5. 时域对照通道

互补滤波估计姿态四元数，从加速度中扣除重力分量得到线加速度，经高通 → 梯形积分 → 高通得到速度，取 400 点（1 s）滑动窗口 RMS。该通道主要用于与频域结果交叉验证。

## 测试结果

在现有条件下，将本系统输出的速度 RMS 与工业级专业振动检测仪进行了对比：**两者读数整数位一致，差异仅出现在小数位**，可满足一般设备状态监测与趋势判断的需求。

### 已知限制

由于缺少标准振动台等标定装置，以下频段的有效性尚未验证：

- **超低频（< 10 Hz 左右）**：预处理高通截止为 1 Hz，速度积分下限为 2 Hz；同时频域积分按 1/f 放大，MEMS 加速度计的低频噪声会被显著放大，该频段读数可信度未知。
- **高频（> 600 Hz）**：采样率 1600 Hz 对应奈奎斯特频率 800 Hz，且预处理低通截止为 600 Hz，因此无法覆盖 ISO 10816 规定的 10–1000 Hz 频段上段。高于 800 Hz 的振动可能因混叠出现在错误频率上。

## 构建与烧录

### 环境

- Keil MDK 5（ARM Compiler 6）
- STM32CubeMX（STM32Cube FW_F4 V1.28.2）
- CMSIS-DSP：工程已包含 `Drivers/CMSIS/Lib/arm_cortexM4lf_math.lib`，并定义宏 `ARM_MATH_CM4`

### 步骤

1. 用 Keil 打开 `MDK-ARM/F411_ICM42670.uvprojx`
2. 编译（F7），通过 ST-Link / DAP-Link 经 SWD 烧录（F8）
3. 串口助手连接 USART1，115200 8N1，即可看到输出

### 使用 CubeMX 重新生成代码时注意

`Core/` 下的文件由 CubeMX 生成，自定义代码只能写在 `/* USER CODE BEGIN */ … /* USER CODE END */` 区块内，否则重新生成时会被覆盖。
